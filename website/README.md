# VirtuPet Website

This is the official website for the VirtuPet mobile app - a credit-based accountability system for reducing screen time addiction.

## 📁 Files Included

- `index.html` - Main landing page
- `privacy.html` - Privacy Policy
- `terms.html` - Terms & Conditions
- `faq.html` - Frequently Asked Questions
- `styles.css` - Complete styling with VirtuPet brand colors
- `assets/` - Folder for images and badges (to be added)

## 🎨 Design Features

- **Brand Colors**: Indigo (#4F46E5) primary, Sky Blue, Emerald, Amber, Rose accents
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile
- **Modern UI**: Clean, minimalist design inspired by the app
- **Smooth Animations**: Hover effects and transitions
- **Interactive FAQ**: Expandable accordion-style questions

## 🖼️ Assets Needed

To complete the website, add these assets to the `assets/` folder:

1. **app-store-badge.svg** - Official App Store download badge
   - Download from: https://developer.apple.com/app-store/marketing/guidelines/
   
2. **app-screenshot.png** - Main app screenshot for hero section
   - Recommended size: 1170x2532px (iPhone mockup)
   - Should show the VirtuPet dashboard with credit ring
   
3. **virtupet-logo.png** (optional) - Logo for enhanced branding

## 🚀 Deployment

### Option 1: GitHub Pages (Free)
1. Create a GitHub repository
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select main branch as source
5. Your site will be live at `https://yourusername.github.io/repository-name/`

### Option 2: Netlify (Free)
1. Sign up at netlify.com
2. Drag and drop the website folder
3. Get instant deployment with custom domain support

### Option 3: Vercel (Free)
1. Sign up at vercel.com
2. Import from GitHub or upload folder
3. Automatic deployments on every update

### Option 4: Custom Hosting
Upload all files to your web server via FTP/SFTP

## 📝 Customization

### Update Contact Information

Search for and replace these placeholder email addresses:
- `support@virtupetapp.com`
- `privacy@virtupetapp.com`
- `legal@virtupetapp.com`

### Update Company Address

Search for `[Your Address]` in:
- `privacy.html`
- `terms.html`

Update with your actual business address.

### Update Jurisdiction

In `terms.html`, search for `[Your Jurisdiction]` and replace with your actual jurisdiction (e.g., "the State of California" or "England and Wales").

### Modify App Store Links

When your app is live, replace `#` in the App Store badge links with your actual App Store URL:
```html
<a href="https://apps.apple.com/app/idYOUR_APP_ID">
```
